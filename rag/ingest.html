RAG 문서 업로드 도구

홈페이지와 보고서를 잘게 나눠 Gemini로 임베딩한 뒤 Supabase documents 테이블에 저장합니다. 입력한 키는 이 브라우저 안에서만 쓰이고 저장되지 않습니다.

1. 키 입력

Project Settings → API Keys. 이 키는 절대 홈페이지 코드에 넣지 마세요.
Google AI Studio → Get API key

2. 문서 선택

권장 파일: index.html, PRD/PRD.md, report/*.md. 자동 불러오기는 GitHub Pages 등 웹 서버에서 열었을 때만 동작합니다. (파일을 더블클릭해 열었다면 직접 선택하세요)
파일글자 수조각 수

3. 업로드

체크하지 않아도 같은 파일 이름의 기존 조각은 지우고 새로 넣습니다.
